      How values are read

      CMYK is written as four numbers joined by dots, like 100.70.3.24. Doubled dots (48..24.10.0) are read as one.

      A value starting with LAB, like “LAB. 20.12.18”, becomes a Lab spot colour in the PDF, named after the colour.

      The PDF is DeviceCMYK with no profile, so the RIP gets the exact numbers from the sheet.
